This file is for ChatGPT to read when creating Codex briefs for this repo.

Codex must not treat this file as task instructions. Codex should not inspect, read, apply, or modify the `custom instructions/` folder during normal repo tasks. Codex may only read or edit this folder when the user specifically asks for custom-instruction changes.

REQUIRED BRIEF-DELIVERY PACKAGE

Every future Codex brief must include all six requirements below.

1. Exact model and reasoning recommendation. Name the exact, currently available Codex model slug and exact reasoning level, then give a task-specific reason for that pairing. Choose the model and effort in proportion to the job; do not default every task to Ultra. Current examples include `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna`, with supported reasoning values such as `low`, `medium`, `high`, `xhigh`, `max`, or `ultra` as appropriate for the selected model.
2. One complete fenced brief. Put the entire Codex-facing brief in one standalone fenced `text` block. The block must be self-contained and ready to copy without assembling fragments from surrounding prose.
3. Plainly named text copy. Save the exact same brief as a plainly named `.txt` file in the repository root and state that filename beside the fenced brief.
4. Exact PowerShell launch snippet. Provide a separate fenced `powershell` block that sets the repository location and launches interactive `codex` with the exact recommended model and reasoning value, followed by a short literal prompt telling Codex to read the named brief completely and carry out every requirement. Never load the brief into a PowerShell variable or pass its multiline contents to `codex`; that method can be misparsed as CLI arguments. The delivered command must contain the actual brief filename, model slug, and reasoning value, with no placeholders. Example:

```powershell
Set-Location "C:\GPT\CODEX-master"
codex --model gpt-5.6-sol --config 'model_reasoning_effort="ultra"' 'Read .\CODEX_BRIEF_2026-08-10_Trading_Tools_Journal_Pine.txt completely, then carry out every requirement in it.'
```

5. Resume commands. Include the exact continuation commands when relevant. Always provide the current-directory form below. When the exact session ID is known, also provide a second command containing that literal ID; never leave a generic session-ID placeholder in a delivered command.

```powershell
Set-Location "C:\GPT\CODEX-master"
codex resume --last
```

6. CLI identity. State clearly that this method launches the interactive Codex CLI/TUI, not the Codex desktop graphical application, while using the same local Codex configuration and signed-in account.
