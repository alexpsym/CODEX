- Run targeted tests and syntax checks for every touched area.
- Do not claim success without verification output.
- Write the final summary text verbatim to summary/CODEX_SUMMARY_latest.txt before pushing.
- Run C:\Users\User\Documents\GPT\PATCH_DESKTOP_PUSH.bat at the end of each job unless the user explicitly says not to. If that file is missing, run the repo-root PATCH_DESKTOP_PUSH.bat.
- Do not push before writing summary/CODEX_SUMMARY_latest.txt.
