### Changes implemented (repo: `/mnt/data/CODEX-master_2.zip`)

#### 1) OANDA + Bybit History UI = period buttons

Updated both history pages to use **exact buttons**:

**DAY, WEEK, MONTH, YEAR, 3 YEARS, COMPLETE**

* OANDA page: `/oanda-history`
* Bybit page: `/bybit-history`

Backend now accepts `{"period":"day|week|month|year|3y|complete"}`.

**Provider constraints handled**

* **OANDA**: the transactions time-range query is capped at **365 days per request**, so **3 YEARS** is fetched by splitting into <=365-day windows. ([developer.oanda.com][1])
* **Bybit**: execution history is capped at **~2 years** (“Get Execution (2 years)”), so **3 YEARS** and **COMPLETE** export the maximum available range (clamped to 730 days). ([bybit-exchange.github.io][2])

#### 2) Watchlist moved + made same size/style as Open Orders/Positions

On the main dashboard:

* Watchlist is now **directly above** Open Orders/Positions.
* Both are the **same width and same panel styling**, with a fixed matching height via `.top-panel`.

#### 3) Auto-run scripts on deploy / service start

`render/master_service.py` already supported `AUTOSTART_SCRIPTS`; I changed it so:

* If **Render env var `AUTOSTART_SCRIPTS` is NOT set**, it defaults to:

  * `bybit_monitor,oanda_monitor,fxweekend-clone`
* If you **do set** `AUTOSTART_SCRIPTS`, it uses your value (including allowing you to disable by setting it to empty).
