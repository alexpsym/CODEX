1. Cashflow-neutral percentage equity curves
- Replaced the six absolute-balance curves with compounded performance indices for Binance, Bybit, Oanda demo/live, and Pepperstone demo/live.
- Every curve starts at exactly 100% immediately before its first eligible trade.
- Trade movement is calculated only as actual net PnL divided by a verified positive analysis balance before the trade.
- Input analysis fields are cleared before the balance timeline is rebuilt. Accepted balance provenance is explicitly enumerated; arbitrary supplied equity_return_pct values, risk-based result_pct values, and contradictory after-balances are not trusted.
- Deposits, withdrawals, and transfers can add a flat timestamped point but cannot move the index.
- Test trades, monthly AUD revaluation rows, invalid trades, and pre-first-trade cashflows remain excluded.
- Chronological sorting and stable deduplication are preserved.
- The chart Y-axis and current summary use percentages; the X-axis remains date-based.
- Equity cache schema 2 identifies cashflow_neutral_compounded_index, base 100, equity_return_pct, and return basis net_trade_result_over_analysis_balance_before_trade. Missing or foreign basis proof makes a snapshot stale.
- API point counts are recomputed from the exact response rows after response filtering. The browser rejects both zero and nonzero count mismatches.
- Canonical verified JavaScript/API counts:

  - BYBIT: 265
  - OANDA DEMO: 45

2. Bybit Open Orders and Positions diagnostics
- Local runtime logs were inspected. They recorded the Bybit source error count but did not preserve the underlying exception reason, confirming the diagnostic gap.
- Signed GET timeouts and request failures now use bounded retries from the existing configured retry limit.
- Every Bybit positions/orders source error records a safe account, source type, endpoint path, category, settlement coin, error type, and meaningful reason.
- Timeout messages explicitly identify timeout and endpoint. HTTP/API errors retain safe HTTP status, retCode, and retMsg details.
- Partial success is retained across Bybit settlement coins/categories and across other brokers.
- Backend and browser sanitizers remove API keys, secrets, signatures, signed URLs, URL queries, and quoted or multiword secret fields. Unstructured fetch, action, and verification errors also pass through the sanitizer.
- Empty messages receive a useful fallback and the browser never renders a dangling colon.
- No real order, cancellation, position-close, or broker mutation request was sent during testing.

4. Watchlist authority and update durability
- The live repository-local watchlist is [].

  4f53cda18c2baa0c0354bb5f9a3ecbe5ed12ab4d8e11ba873c2f11161202b945
- Empty per-file state is authoritative; it is never treated as missing.
- A matching empty manifest entry acts as a deletion tombstone if the mirror is temporarily absent, preventing replay from an older aggregate.
- Invalid authoritative per-file JSON now blocks aggregate rewrite, so a corrupt mirror cannot overwrite a healthy aggregate with an accidental empty value.
- watchlist.json, state_manifest.json, legacy stateManifest.json, and state_backup.json are ignored runtime state. The three formerly tracked state files are removed from Git while their healthy local copies remain intact.
- PATCH_DESKTOP_PUSH.bat no longer unstages the intended tracked-file removals.
- INSTALL.bat now handles the one-time tracked-to-ignored migration before a fast-forward merge:
  - byte-preserves genuinely modified empty or legitimate-symbol state;
  - allows untouched repository bootstrap state to disappear;
  - creates a canonical empty watchlist/manifest tombstone when an unrelated modified aggregate could otherwise replay the removed bootstrap watchlist;
  - restores partially moved files in a finally block and retains the backup if update fails.
- Isolated restart tests run the startup path twice, verify a legitimate BTCUSDT addition survives, and verify its deletion remains empty.
- A real temporary Git/PowerShell four-case matrix verifies authoritative empty, legitimate symbol, untouched stale bootstrap, and mixed-status stale aggregate migrations.
- No production Local Trading Tools process was restarted because that could start configured trading-related components; restart/update semantics were exercised in isolated regression environments.
