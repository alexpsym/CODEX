Exact changes:
1. The fast required probe now checks exactly `flask`, `openpyxl`, and `requests`.
2. A warm required-ready launch skips pip regardless of whether MetaTrader5 exists.
3. A missing required package triggers same-interpreter installation of only `Flask openpyxl requests`; the launcher no longer installs the full manifest containing MT5.
4. Required packages are always re-probed after installation. The install process exit code is advisory; startup exits only if the required recheck still reports a missing package.
5. MetaTrader5 has its own presence probe. Absence produces a clear warning and continues to Uvicorn.
6. Optional MT5 installation is off by default. If explicitly requested with `SPREAD_MONITOR_INSTALL_OPTIONAL_MT5=1`, a failed install or failed post-install probe warns and remains nonblocking.
7. `SPREAD_MONITOR_SKIP_REQUIREMENTS_INSTALL` remains supported.
8. `spreads-clone/requirements.txt` and all MT5/Spread application code were left unchanged; the global launcher simply no longer consumes the optional MT5 entry during required repair.
