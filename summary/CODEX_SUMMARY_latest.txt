Decimal comparison method:
- Source values are converted with `Decimal(str(value))` without rounding through display precision.
- Means, medians, planned target R, captured target R, and stop-distance comparisons use Decimal arithmetic.
- Recommendation direction uses exact Decimal comparisons only:
  - winner stop mean > loser stop mean: Increase stop
  - winner stop mean < loser stop mean: Decrease stop
  - recommended target R > planned-target median: Increase target
  - recommended target R < planned-target median: Decrease target
- Exact-tie goal preferences run only when the Decimal values are exactly equal.

FX net-R recovery priority now enforced:
- Verified net profit / verified original monetary risk.
- Verified stored original net R, including stored `R-Multiple` only when provenance proves original entry, original stop, and net result.
- Reconstructed opening-conversion net R when original entry/stop, units, opening quote-to-home conversion, and net P/L are available.
- Verified net-equivalent price R only with positive proof.
- Direct price R is not accepted from missing cost/partial/financing metadata.
