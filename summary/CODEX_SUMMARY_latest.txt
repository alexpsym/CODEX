What changed:
- Removed percentile-based spread display/classification from the Spread Monitor UI path.
- Retired LOW_MAX_PERCENTILE, HIGH_MIN_PERCENTILE, MIN_CURRENT_SPREAD_PERCENTILE_SAMPLES, percentile_rank, and classify_spread from spread_core.py.
- broker_cell now returns category="neutral" for every valid numeric spread value, including 0.0, regardless of sample count.
- Missing or invalid spread data still returns category="unavailable".
- Spread percentages still display in percentage-unit format via format_spread_pct, including 0.00000% for zero spread.
- Spread points still display when available, including Pepperstone current-only rows as percentage / points.
- Removed visible percentile legend wording from spread_app.py and replaced it with: "Spread values are shown as percentage of bid/ask midpoint. Points are shown when available."
- Removed green/orange/red percentile classes from the app stylesheet.
- Pepperstone remains manual-import only, uses the repo path mt5-clone/pepperstone_spreads_latest.json plus the existing MT5 fallback path, and does not use live MT5 fetchers in the web app.
- A single Pepperstone import is enough to produce a useful current spread row immediately, without historical sample buildup.
- OANDA current spread fetch and auto-refresh behavior were kept current-only with no historical-percentile dependency.
- Existing broker selector buttons for Oanda and Pepperstone remain in spread_app.py.
