1. Pine Script offset alerts
- Root cause: the three offset values were rendered only with dashed line.new objects. TradingView could expose the base EMA/VWAP/Volume plots as alert sources, but it had no plot series or alert conditions for the offsets.
- Added gated hidden plot series titled exactly "9 EMA Offset", "20 EMA Offset", and "VWAP Offset" while retaining all existing base plots and dashed visual offset lines.
- Added nine unique global alertcondition entries: crossing, crossing above, and crossing below for each supported offset. Every condition references only its corresponding gated offset series.
- Raw crossover/crossunder expressions are evaluated consistently and gated with barstate.isconfirmed, providing bar-close confirmation and preventing duplicate/repainting behaviour. A disabled line produces na and cannot trigger.
- No generic alert() call or base-line crossing condition was added. Pine does not guess Buy/Sell from the side of an offset; the calculator-authored webhook URL/JSON remains the source of the intended action.
- Added static/model regressions for intervening EMA/VWAP crossings, true offset crossings in both directions, each EMA offset, disabled lines, unique selector titles, confirmed-bar gating, and retained plots/visuals.
