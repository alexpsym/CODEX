Changes made:
- Fixed the MT5 Pepperstone spread export in mt5-clone/MQL5/Experts/Trader.mq5:

  - The chart suffix is now reused for every configured base symbol, so an EURUSD.a chart can resolve GBPUSD -> GBPUSD.a and USDJPY -> USDJPY.a before falling back to Market Watch scanning.
  - Export logs now show requested/resolved pairs, e.g. Pepperstone spread export resolved EURUSD -> EURUSD.a.
  - Missing matches now log Pepperstone spread export skipped EURUSD because no matching MT5 symbol was found.
  - SymbolSelect/SymbolInfoDouble now use the resolved MT5 symbol.
  - Export JSON now includes both symbol (configured/base, e.g. EURUSD) and mt5_symbol (resolved MT5 symbol, e.g. EURUSD.a), while preserving bid, ask, spread_pct, digits, point, and timestamp.
