1. Journal equity curves
- Raised the Trading Journal view-cache schema to version 6 and added snapshot IDs, snapshot fingerprints, current-source fingerprints, verified equity metadata, and exact per-account point-count coverage.
- A missing, incompatible, stale, or unverified cache is never returned as authoritative ok=true data. GET /api/trading-journal now returns an empty 202 while a rebuild is active or an empty 503 with the actual failure/rebuild reason.
- Added narrow POST /api/trading-journal/equity/refresh and GET /api/trading-journal/equity/refresh/status operations. Refresh is single-flight, queue/poll safe, cancellation safe, and can recover from an orphaned or completed task whose pending flags were stale.
- Master-journal startup queues a cache-only build after durable restore. The cache-only path does not fetch brokers and does not call a workbook writer.
- Master-journal timelines now seed from source_payload["balances"] as well as cashflow/trade rows, preserving the authoritative currency and zero-balance anchors needed by workbook rows.
- The browser refresh action now POSTs a real rebuild request and polls status. It distinguishes building, stale, incompatible, failed, and current states.
- "No equity data" is shown only when a current-fingerprint, verified snapshot proves zero eligible points for the selected account.
