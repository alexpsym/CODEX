2. Local Bybit ATR-percentage and liquidity scanner

- Added render/atr_scanner.py, render/static/atr_scanner.js, local page/API routes in render/master_service.py, and documentation in render/README.md.
- Instrument discovery paginates public V5 Get Instruments Info and retains only status=Trading, contractType=LinearPerpetual, quoteCoin=USDT, settleCoin=USDT, non-prelisting contracts. It is not tied to the Alerts symbol list.
- Tickers are fetched once. Liquidity uses turnover24h (not volume24h), exact midpoint spread `(ask-bid)/((ask+bid)/2)*100`, then per-symbol order-book quote notional `price*quantity` inside the inclusive configured band on each side.
- Every liquidity gate uses AND. Invalid, missing, crossed, stale, or unverified data fails closed. ATR is fetched only after instrument, manual-exclusion, turnover, spread, and order-book gates.
- Defaults are: minimum turnover 20,000,000 USDT; maximum spread 0.10%; depth band +/-0.10% of midpoint; minimum bid depth 25,000 USDT; minimum ask depth 25,000 USDT; maximum book age 30 seconds; ATR length 14; rank by 1m; Top 10; automatic refresh every 60 seconds.
- ATR is Wilder/RMA true range: max(high-low, abs(high-previous close), abs(low-previous close)). ATR percentage is ATR divided by the same timeframe closed-candle close, multiplied by 100. The still-forming candle is excluded using Bybit/server interval boundaries.
- The six unambiguous timeframes are 1m, 5m, 1h, 1D, 1W, and 1Mo, mapped to Bybit intervals 1, 5, 60, D, W, and M. Requests ask for 201 rows so 200 closed candles remain when the newest row is forming; newer instruments are accepted only with enough valid contiguous closed history.
- Raw values rank descending with a deterministic symbol tie-break. Formatting uses five ATR decimal places but never affects rank. Missing values are N/A and cannot rank for the selected timeframe.
- The table shows all six ATR values, turnover, spread, bid/ask depth, liquidity/data state, exact ranking basis, eligible/excluded counts and reasons, progress, freshness, and last successful update. Changing timeframe or Top N reranks locally and recomputes the Qualified/Excluded views and basis without contradictory saved-timeframe counts.
- Persisted local settings cover every threshold and manual exclusions; Reset restores defaults. Manual exclusions accept comma/newline input, normalize/deduplicate case and whitespace, and are bounded to 1,000 symbols and 50,000 input characters. All numeric/text settings have server-side type/range checks.
- Explicit exclusion reasons cover inactive, wrong product, manual exclusion, turnover, spread, bid depth, ask depth, missing/invalid market data, insufficient ATR history, and transient upstream failure. Kline reasons are preserved per timeframe rather than conflating malformed data with a network failure.
- Requests use bounded concurrency, pacing, timeout, retries, and backoff. ATR caches are keyed by symbol/timeframe/length and remain valid until the next candle boundary, so daily/weekly/monthly history is not fetched each minute.
- Browser callers share one in-flight refresh. A settings save during refresh queues one non-overlapping follow-up. Transient failures retain visibly stale last-known-good data with age and scoped error; first-load/all-scope failures return explicit errors rather than an empty HTTP-200 success.
- The public source resolver allows only canonical HTTPS api.bybit.com or api.bytick.com origins, strips no credentials because none are accepted, rejects paths/query/fragments/lookalikes/testnet/demo hosts, and reports authenticated=false.
- Help text states that turnover, spread, and order-book depth are liquidity proxies and cannot guarantee fills or future liquidity.

3. Separate Pepperstone Market Watch ATR feed and desktop window

- Added mt5-clone/MQL5/Experts/MarketWatchATRPercentFeed.mq5, mt5-clone/atr_percent_window.py, and mt5-clone/MARKET_WATCH_ATR_FEED.md.
- The EA enumerates selected Market Watch symbols with SymbolsTotal(true)/SymbolName(index,true), classifies forex using SYMBOL_TRADE_CALC_MODE_FOREX or SYMBOL_TRADE_CALC_MODE_FOREX_NO_LEVERAGE, and keeps non-forex/unavailable entries diagnostic rather than inventing a volume filter.
- It lazily creates iATR handles for PERIOD_M1, PERIOD_M5, PERIOD_H1, PERIOD_D1, PERIOD_W1, and PERIOD_MN1; waits for history; reads CopyBuffer shift 1 and iClose shift 1; rejects EMPTY_VALUE, non-finite, missing, and zero-close data; and publishes `(ATR/close)*100`.
- A bounded 500 ms timer processes four symbols per pass and skips unchanged closed bars. Handles are reused and every valid handle is released in OnDeinit. OnTick is empty and no trade function exists.
- The independent JSON feed and Python window show all six timeframes, selected-timeframe Top 10 rank, deterministic ties, refresh time, Loading/N/A/Error/Stale state, last-good retention, and a diagnostic tab. They do not share the spread feed/window's IPC, title, styles, or process identity.
