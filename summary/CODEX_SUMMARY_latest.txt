MarketWatchSpreadPercent replacement summary

Files changed:
- Deleted obsolete chart-overlay EA:
  - mt5-clone/MQL5/Experts/MarketWatchSpreadPercent.mq5
- Added feed-only MT5 EA with optional desktop auto-launch:
  - mt5-clone/MQL5/Experts/MarketWatchSpreadPercentFeed.mq5
- Added separate desktop pop-out window app:
  - mt5-clone/spread_percent_window.py
- Updated this summary:
  - summary/CODEX_SUMMARY_latest.txt

What changed:
- Replaced the failed chart-drawn spread table with a two-part spread monitor.
- The new MT5 EA is feed-only and draws nothing on the chart.
- The feeder now attempts to auto-launch the separate desktop pop-out when attached to a chart.
- Auto-launch uses the Windows ShellExecuteW API through shell32.dll, so MT5 must have Allow DLL imports enabled for this EA.
- DLL imports are only used to open the desktop window; the EA still does not request trading permission and does not trade.
- If DLL imports are disabled, the feeder continues writing the JSON feed and prints a clear Journal message explaining that auto-launch needs Allow DLL imports.
- The feeder reads selected Market Watch symbols with SymbolsTotal(true) and SymbolName(index, true).
- The feeder fetches Bid/Ask with SymbolInfoTick and calculates:
  spread_price = ask - bid
  midpoint = (ask + bid) / 2
  spread_percent = (spread_price / midpoint) * 100
  spread_points = spread_price / SYMBOL_POINT
- The feeder writes JSON to the MT5 common files folder using FILE_COMMON.
- Default feeder output file:
  MarketWatchSpreadPercentFeed.json
- Invalid ticks, zero Bid/Ask, zero midpoint, and zero point values export safely with null/N/A fields.
- The feeder uses EventSetMillisecondTimer with default UpdateIntervalMs = 100 and stops the timer on deinit.
- The feeder does not include Trade.mqh and does not call trading/order APIs.
- The desktop app is a real separate Tkinter window that can be moved and resized by the OS window frame.
- The desktop table defaults to Symbol and Spread % only.
- Bid and Ask are not shown in the desktop table.
- Optional Spread Points display is available with:
  python mt5-clone/spread_percent_window.py --show-points
- Desktop defaults:
  refresh interval 150 ms
  font size 12
  decimal places 5
  feed file path %APPDATA%\MetaQuotes\Terminal\Common\Files\MarketWatchSpreadPercentFeed.json
- EA auto-launch defaults:
  LaunchDesktopWindow = true
  PythonExecutable = C:\Users\User\miniconda3\python.exe
  DesktopWindowScriptPath = C:\Users\User\Documents\GPT\CODEX-master\mt5-clone\spread_percent_window.py
  DesktopWindowRefreshMs = 150
  DesktopWindowDecimals = 5
  DesktopWindowShowPoints = false
- The desktop app handles a missing feed file with a clear status message.
- The desktop app handles temporary file write/read collisions by retrying instead of crashing.
- Header sorting is implemented:
  Symbol first click A-Z, second click Z-A
  Spread % first click largest-smallest, second click smallest-largest
- N/A spread values sort to the bottom when sorting by Spread %.
- Symbol suffixes are preserved as supplied by the feed.
